## 说明

- 都是空数据界面（干净的浏览器上下文，localStorage/IndexedDB 为空），论文里若需要有内容的图，得另行造数据。
- 走生产构建而非 dev server：`import.meta.env.DEV` 才出现的调试面板不会入镜。
- 最新版里 8 个页面（角色/技能树/祈愿/世界地图/工业点数/甘特/新手引导/研究）已归入「废弃页面」，默认关闭，
  截图时预置了 `enabled_deprecated_v1` 把它们捡回来才拍到。
- `/flow-tasks`、`/history` 在后期只是老链接的重定向，不重复收录。
- 每个目录下的 `_shots.json` 记录了当次每条路由实际落在哪个页面。

## 重拍

临时 worktree 签出目标 commit → junction 复用主仓库 node_modules → `vite build` → `vite preview` →
Playwright 按该版本 `src/routes/AppRoutes.jsx` 里的路由表逐页截图。

注意：清理 worktree 前必须先 `rmdir` 掉 node_modules 那个 junction，否则删除会顺着它走进主仓库。
