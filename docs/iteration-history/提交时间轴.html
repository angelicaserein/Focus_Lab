Reproduce

这张图的数据来自下面第一条命令，可以随时重跑。

# 每个功能页各自的迭代史
git ls-files src/pages | %{ ($_ -split '/')[2] } | sort -Unique | %{
  "### $_"; git log --pretty=format:"  %ad %s" --date=short -- "src/pages/$_"; "" }

看某个功能具体改了什么：git log -p --date=short -- src/pages/Focus

追某几行是哪次改的：git log -L 20,40:src/pages/Focus/index.jsx

看一个功能从出生到现在的净变化：git diff <首次提交>..HEAD -- src/pages/Aquarium
