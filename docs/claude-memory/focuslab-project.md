FocusLab：React+Vite+Electron 的 ADHD 数字生产力工具，研究方法是 Case-based Participatory Design，单一有 ADHD 倾向的成人参与者。导师 Paul。

关键约束与方向（截至 2026-06）：
- **数据收集被冻结**：正式用户测试 / 收集参与者反馈需等伦理批准通过。当前只做非正式原型迭代，不能把非正式数据当研究数据。
- **三个研究问题**：RQ1 参与式设计过程；**RQ2 = 在 sprint-based 协同设计中整合 GenAI 做快速原型（被 Paul 点名为创新亮点，学术空白）**；RQ3 最终工具成效。
- 设计三方张力（AI 倾向标准化 / 设计师 / 参与者是经验专家）本身是研究素材。
- 已完成的功能原型很完整：Focus 计时、任务数据库(多 database+自定义列)、备忘录、DDL 提醒、Analytics、情景配置、奖励系统、双语 i18n。

新功能优先从会议清单的 🟡 项里挑：AI 笔记→任务（已做，见 [[ai-three-mode-pattern]]）、双 AI 助手分离、情景智能推荐、DDL 地平线/brain-weather 可视化。
